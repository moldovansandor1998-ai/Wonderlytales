# Wonderly Tales Studio

Production system for creating multilingual animated series with versioned 3D assets.

## MVP
- Next.js Studio
- Supabase production database
- Shot Schema v1
- Render/QC job model
- Blender/ElevenLabs workers added in later milestones

## Core rule
Characters and recurring locations are versioned fixed assets. A shot is a structured production document, not a free-form prompt.
